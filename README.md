# Aplikasi To-Do List

## Deskripsi
Aplikasi sederhana berbasis PHP untuk mencatat dan mengelola tugas harian.

## Fitur
- Menambahkan tugas baru
- Menentukan tanggal tugas
- Menampilkan daftar tugas
- Mengubah nama dan tanggal tugas
- Menandai tugas selesai atau belum selesai
- Menghapus tugas

## Struktur Folder
- `index.php` - Halaman utama dan kode program
- `README.md` - Dokumentasi proyek

## Cara Menjalankan
1. Simpan folder `todolist` di `C:\xampp\htdocs\`.
2. Jalankan Apache melalui XAMPP Control Panel.
3. Buka `http://localhost/todolist/index.php` di browser.
